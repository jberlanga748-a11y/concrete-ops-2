# Apex HQ Pilot Setup Checklist

Use this checklist to set up a simple 10-day contractor pilot without turning the pilot into a custom build.

## Current Goal

Get the contractor through one real office-to-field workflow:

Lead or customer -> estimate -> approved job -> crew assignment -> field photo -> daily report -> delivery ticket -> pre/post-pour checklist -> printed estimate or job packet.

## What John Needs Before Setup

- [ ] Company legal/display name.
- [ ] Main owner/admin name.
- [ ] Main owner/admin email.
- [ ] Main owner/admin phone number.
- [ ] Business phone, email, website, and service area if they want it shown in print packets.
- [ ] Name and email for one foreman.
- [ ] Name and email for one employee.
- [ ] One real active job to start with.
- [ ] One customer name, address, phone, and email if available.
- [ ] One current lead or upcoming quote opportunity.
- [ ] Basic estimate scope and rough line items for one estimate.
- [ ] Confirmation that demo mode stays off for the contractor pilot app.
- [ ] Primary trade set to the contractor's real trade in Settings -> Company profile. For the fencing pilot, set it to Fencing: on the Basic package that switches the workspace to the simplified fence front door (calm Today home, 4-step estimates, concrete-only tools hidden). Upgrading the package or changing the trade brings the full app back.

## Setup Checklist

- [ ] Confirm company name and contact info.
- [ ] Add owner/admin user.
- [ ] Add 1 foreman.
- [ ] Add 1 employee.
- [ ] Add 1 customer.
- [ ] Add 1 lead.
- [ ] Add 1-3 active jobs.
- [ ] Create 1 estimate.
- [ ] Mark estimate sent if appropriate.
- [ ] Approve estimate if it is ready.
- [ ] Convert approved estimate to job.
- [ ] Assign foreman to job.
- [ ] Assign employee to job.
- [ ] Confirm foreman can log in on mobile.
- [ ] Confirm employee can log in on mobile.
- [ ] Confirm field users only see assigned/allowed field-safe information.
- [ ] Upload 1 jobsite photo.
- [ ] Create 1 daily report.
- [ ] Submit the daily report.
- [ ] Add 1 delivery ticket.
- [ ] Complete 1 pre-pour checklist.
- [ ] Complete 1 post-pour checklist.
- [ ] Print or copy 1 estimate.
- [ ] Print 1 daily report or job packet.
- [ ] Ask for feedback after day 3.
- [ ] Schedule end-of-pilot review call.

## Contractor 10-Day Test Plan

Ask the contractor to test these actions during normal work:

- [ ] Add or update a lead.
- [ ] Create or update a customer.
- [ ] Create and send/copy/print an estimate.
- [ ] Convert an approved estimate into a job.
- [ ] Assign a foreman and employee to a job.
- [ ] Have the foreman open the assigned job on a phone.
- [ ] Have the employee open the assigned job on a phone.
- [ ] Clock in or check time tracking if they are ready to test time.
- [ ] Upload at least one jobsite photo from the field.
- [ ] Submit one daily report from the field.
- [ ] Add one delivery ticket.
- [ ] Complete one pre-pour checklist.
- [ ] Complete one post-pour checklist.
- [ ] Print or save one job packet.
- [ ] Tell John where the workflow felt slow, confusing, or unnecessary.

## Day 3 Feedback Questions

- [ ] Did you and the crew know where to start after logging in?
- [ ] Did field users see the job information they needed?
- [ ] Did field users see anything they should not have seen?
- [ ] Was uploading a photo clear enough?
- [ ] Was the daily report too long, too short, or missing anything?
- [ ] Were delivery tickets easy to enter?
- [ ] Were pre-pour/post-pour checklists useful or annoying?
- [ ] What was the most confusing button, label, or page?
- [ ] What did you avoid using?
- [ ] What would make this easier to use tomorrow?

## End-of-Pilot Review Questions

- [ ] Did Apex HQ save time or reduce back-and-forth?
- [ ] Which workflow was most valuable?
- [ ] Which workflow felt unnecessary?
- [ ] Did the office trust the field data coming in?
- [ ] Did foremen/employees keep using it after the first day?
- [ ] Did job photos, daily reports, delivery tickets, or packets help with documentation?
- [ ] Were permissions and field visibility correct?
- [ ] What is the one thing that must improve before paying for it?
- [ ] Would you use this on the next real job?
- [ ] Would you recommend this to another concrete contractor?

## What Not To Turn On During First Pilot

- [ ] Do not turn on demo mode for the contractor pilot app.
- [ ] Do not seed demo data into the contractor pilot app.
- [ ] Do not connect billing/subscriptions.
- [ ] Do not connect QuickBooks/accounting.
- [ ] Do not add SMS/email sending yet.
- [ ] Do not add customer portal access yet.
- [ ] Do not add payroll/pay rates.
- [ ] Do not add experimental AI workflows.
- [ ] Do not add multi-company signup.
- [ ] Do not add a large custom feature before day-3 feedback.
- [ ] Do not change field role permissions during the pilot unless there is a confirmed blocker.

## Success Criteria

- [ ] Owner/admin can log in.
- [ ] Foreman can log in on mobile.
- [ ] Employee can log in on mobile.
- [ ] One real job is active in the system.
- [ ] One field photo is uploaded.
- [ ] One daily report is submitted.
- [ ] One delivery ticket is recorded.
- [ ] One checklist is completed.
- [ ] One estimate or job packet is printed/copied.
- [ ] No field user sees leads, estimates/pricing, full customers, Settings, payroll, profit/margin, or office-only notes.
- [ ] Contractor gives clear day-3 feedback.

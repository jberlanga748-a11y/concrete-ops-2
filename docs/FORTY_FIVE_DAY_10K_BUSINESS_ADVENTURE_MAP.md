# Apex HQ 45-Day $10K Business Adventure Map

Status: aggressive founder-led revenue sprint
Goal: reach $10,000/month in recurring revenue or get as close as possible while collecting real cash, proof, referrals, and repeatable onboarding.

## The Truth

To make $10,000/month in 45 days, Apex HQ cannot rely on cheap app-only plans.

The fast path is not:

```text
100 customers at $99/month
```

The fast path is:

```text
5-10 serious contractor owners buying high-value founder packages
```

The sprint goal is:

```text
Close serious owner-led contractors into $999/month founder packages.
```

## Main 45-Day Offer

Package name:

```text
Apex HQ Contractor Growth Package
```

Use trade-specific names only when useful:

```text
Apex HQ Fence Growth Package
Apex HQ Concrete Growth Package
Apex HQ Contractor Growth Package
```

The brand stays for all contractors and trade businesses.

Price:

```text
$999/month founder price
```

Setup:

```text
Normally $1,000-$2,500
Waived or discounted for the first 5 founder customers
```

Website builds:

```text
$1,000-$3,500 one-time

```

## North Star

The real 45-day mission:

```text
payment -> onboarding -> first workflow -> proof -> referral -> repeatable offer
```

Do not chase public launch noise while trying to close the first revenue sprint.

## Sunday Customer Mission

Sunday is not just onboarding. Sunday is the start of proof.

Before Sunday:

- confirm the price
- invoice before access
- collect company info
- confirm website scope
- explain AI, measuring, and payroll-prep boundaries
- choose one first workflow

During Sunday:

- set up one real workflow
- enter one real lead or job
- create or review one estimate
- show schedule and field handoff
- have one employee/field user log in if possible
- capture one photo/report/proof item if possible
- identify one problem Apex HQ helped him stop chasing

After Sunday:

- write private proof notes
- ask what confused him
- ask what helped
- ask for two referral names after he sees a useful result
- do not ask for a public testimonial until value is real

## First Workflow Only

Every new customer starts with one workflow:

```text
Lead -> Estimate -> Job -> Schedule -> Field Proof -> Owner Review
```

Additional workflows wait until the first workflow works.

This prevents support overload.

## 45-Day Calendar

### Days 1-3: Lock The First Customer And Build The List

Goals:

- close Sunday customer cleanly
- collect payment or clear invoice agreement
- collect setup info
- build a target list of 100 contractors
- contact 30 warm/local prospects

Daily target:

```text
20 prospects reviewed
10 calls
10 texts/emails
3 follow-ups
1 referral ask
notes logged same day
```

### Days 4-7: Turn First Customer Into Proof

Goals:

- run Sunday onboarding
- set up the first workflow
- write the first private proof note
- ask for 2 referral names if value is real
- book 3 walkthroughs
- post one founder story or contractor workflow post

### Days 8-14: First Sales Push

Goals:

- 50 calls
- 50 texts/emails
- 5 demos
- 2 offers
- 1 second paid customer
- ask every live conversation for one referral

Primary message:

```text
I built Apex HQ for contractors who are growing past texts, paper, and scattered apps. I am opening a small founder group and setting up one real workflow at a time.
```

### Days 15-21: Founder Group Push

Goals:

- push first 5 founder customers
- run 5-7 demos
- close 2 more founder packages
- focus on fencing, concrete, hardscape, excavation, roofing, remodeling, and small GCs
- create one simple demo video if the app path is clean

### Days 22-30: Tighten The Pitch

Goals:

- use objections to improve the demo
- aim for 5 total paid customers
- start weekly customer check-ins
- keep $999 for growth/service customers
- use $249-$499 only for smaller software-only customers

### Days 31-45: Close Toward $10K

Goals:

- double down on what closed
- ask first customers for referrals
- talk to supplier/material yards and local contractor groups
- run 10-15 more demos
- close the remaining customers toward 10 paid accounts


## Proof Capture

Do not ask for public testimonial too early.

Ask:

```text

```

Then:

```text
Would you be okay if I used that as an anonymous quote while we keep improving the system?
```

## Agent Operating System

Use agents daily.

Morning GTM Agent:

- top 10 prospects
- call/text priorities
- risky claims to avoid

Research Agent:

- verify 5 companies/day
- find services, owner/contact clues, and fit rating

Sales Draft Agent:

- write personalized texts/emails
- write follow-ups from call notes

Call Notes Agent:

- turn rough notes into next step, objection, and follow-up

Demo Prep Agent:

- prepare walkthrough path for each prospect

Customer Success Agent:

- prepare onboarding, day-3 check-in, day-10 review, and support boundaries

John's job:

- call
- text
- demo
- close
- collect payment
- get referrals

Do not let agents replace John's voice yet. Contractors buy John first, the system second.

## Risk Rules

Do not say:

- AI runs everything
- Apex HQ will get you jobs
- this replaces payroll
- this replaces your accountant
- this guarantees growth
- unlimited support
- I will build whatever you need

Say:

```text
Apex HQ helps organize the work, speed up follow-up, prepare better information, and show what needs attention. You still approve important decisions.
```

# Apex HQ Offer Ladder And Services

Status: revenue/offer planning

## Goal

Create a clear path from first conversation to larger customer value without selling custom software.

## Offer Ladder

| Step | Offer | Price Direction | Purpose |
| --- | --- | ---: | --- |
| 1 | 20-minute walkthrough | free | qualify pain |
| 2 | 14-day founder pilot | free or low-friction | prove workflow |
| 3 | Basic founder plan | about $99/mo | entry customer |
| 4 | Premium founder plan | about $249/mo | main offer |
| 5 | Setup package | $500-$2,500 | fund onboarding |
| 6 | Elite support | $799-$1,500+/mo | hands-on growth/workflow help |
| 7 | Annual plan | 10%-15% discount or setup waived | cash flow and retention |

## Walkthrough Offer

Use when:

- first outreach
- referral intro
- partner conversation

Promise:

- practical workflow demo
- no pressure
- honest fit check

Do not promise:

- custom build
- guaranteed leads
- full migration

## Founder Pilot Offer

Use when:

- contractor has real workflow pain
- owner/admin is engaged
- one workflow can be tested

Pilot:

- 14 days
- one workflow
- day-3 check-in
- day-10 review
- founder pricing if value is proven

## Setup Services

Sell when:

- customer wants help getting started
- owner has no time
- templates/process cleanup is needed

Setup can include:

- company profile
- users/roles
- first customer/job
- first estimate workflow
- field proof checklist
- basic training

Do not include:

- custom app features
- accounting/payroll migration
- deep integrations
- unlimited support

## Elite Growth Partner Services

Sell only to customers with clear value and budget.

Could include:

- monthly business review
- proposal/template improvement
- follow-up process
- website lead intake planning
- referral/review process
- field workflow cleanup

Positioning:

```text
This is for contractors who want Apex HQ plus hands-on help cleaning up operations and growth.
```

## Upsell Triggers

Basic to Premium:

- more than one crew
- more estimates needing follow-up
- photos/reports matter
- owner wants better visibility

Premium to Elite:

- wants hands-on setup
- wants growth help
- needs templates/process cleanup
- owner wants monthly accountability

Monthly to Annual:

- 60+ days of usage
- value is clear
- support load is stable
- owner trusts the system

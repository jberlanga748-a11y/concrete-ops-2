# Apex HQ Retention And Expansion Playbook

Status: customer growth plan

## Goal

Keep customers long enough for Apex HQ to become part of how they run work.

A $1M+ business needs retention, not just new sales.

## Retention Principle

Customers stay when Apex HQ becomes tied to a weekly habit:

- estimate follow-up
- job setup
- field photo/report proof
- owner review
- billing readiness
- customer/GC follow-up

## First 30 Days

Week 1:

- complete first workflow
- confirm field action
- check owner value

Week 2:

- review first proof/report/follow-up
- remove friction
- ask what still went through text

Week 3:

- add second workflow only if first is working
- introduce package value

Week 4:

- run value review
- ask for referral
- ask for testimonial if real value exists

## Customer Health Score

| Signal | Healthy | Risk |
| --- | --- | --- |
| Owner login | weekly | no login in 7+ days |
| Field action | photo/report/update submitted | no field use |
| Job/estimate created | active workflow | empty account |
| Support sentiment | asks usage questions | confused/frustrated |
| Value proof | says it reduced chasing | cannot name benefit |

## Churn Warning Signs

- no first workflow completed
- owner does not log in
- field user never uses it
- customer asks for unrelated features
- support issues repeat
- price objection returns before value is proven
- "we are too busy" after setup

## Save Plays

If no usage:

```text
Let's narrow this back to one job and one field action so we can tell if Apex HQ is actually useful.
```

If crew adoption is weak:

```text
Do not roll this out to everyone yet. Let's pick one foreman and one action: photo or report.
```

If owner is overwhelmed:

```text
We do not need to use the whole platform. Let's use Apex HQ only for the part you are tired of chasing.
```

## Expansion Triggers

Upsell to Premium when:

- Basic customer has multiple jobs/crews
- owner wants better proposals
- field proof becomes important
- follow-up tracking matters

Upsell to Elite when:

- owner wants hands-on setup
- customer needs templates/process cleanup
- website/lead intake help is requested
- monthly business review would be valuable

Ask for annual when:

- customer has used Apex HQ for 60+ days
- value is clear
- support load is stable
- renewal trust exists

## Monthly Business Review

Ask:

- What did Apex HQ help you keep organized this month?
- What still went through text or memory?
- What job had the most missing proof?
- What estimate needed follow-up?
- What should we clean up next?
- Who else should see this?

## Referral Moment

Ask after a clear win:

```text
Who do you know that does good work but still has job notes, photos, estimates, or follow-ups scattered everywhere?
```

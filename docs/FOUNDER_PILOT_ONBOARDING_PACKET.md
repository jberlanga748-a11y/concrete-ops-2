# Apex HQ Founder Pilot Onboarding Packet

Status: draft for interested contractors
Audience: contractor owners/admins considering a 14-day founder pilot

## Short Version

Apex HQ is opening a small founder pilot for contractors who want estimates, jobs, crews, photos, reports, and follow-ups organized in one place.

The pilot does not try to switch your whole company at once. We pick one real workflow, set it up, test it for 14 days, and decide if it is worth continuing.

Current readiness:

- guided walkthroughs are usable now
- paid pilots should stay narrow and founder-led
- public self-serve signup is not the offer yet

## Who The Pilot Is For

Good fit:

- contractor with active jobs or estimates
- owner/admin is willing to test one workflow
- field user or foreman can try one simple action
- current workflow depends on texts, spreadsheets, paper, phone photos, or memory
- company wants cleaner job handoff, field proof, or follow-up

Poor fit:

- needs full accounting/payroll replacement immediately
- needs enterprise procurement or custom contracts before trying anything
- wants automatic lead guarantees
- wants custom software before testing the core workflow
- field team will not try even one simple action

## Pilot Goal

Prove one practical workflow:

```text
Estimate or job setup -> crew/field handoff -> photo/report/proof -> owner review -> follow-up
```

## What The Pilot Includes

- 14-day founder pilot
- one setup/kickoff call
- one selected workflow
- owner/admin setup help
- one field user or small crew test
- day-3 check-in
- day-10 value review
- end-of-pilot decision call
- founder pricing option if the pilot proves useful

## What The Pilot Does Not Include

- guaranteed leads
- automatic email or text sending
- ad publishing
- accounting/payroll replacement
- enterprise rollout
- custom feature builds
- AI making decisions without review
- full company migration

## What We Need From You

- one owner/admin contact
- one field lead or foreman if field workflow is tested
- one real estimate, job, or workflow to test
- honest feedback
- day-3 check-in availability
- day-10 review availability

## Pilot Timeline

Internal operator templates: use `docs/PILOT_KICKOFF_AND_CHECKIN_TEMPLATES.md` for kickoff intake, day-3 check-in, day-10 value review, support issue capture, and continue/adjust/stop decisions.

| Day | Step | Goal |
| --- | --- | --- |
| Day 0 | Kickoff/setup | pick workflow and set up users/job |
| Day 1 | Owner/admin test | confirm owner can see workflow |
| Day 2 | Field action test | photo/report/job update tested |
| Day 3 | Check-in | remove friction and confirm next step |
| Day 4-9 | Real workflow use | test on actual work |
| Day 10 | Value review | decide if there is enough value |
| Day 14 | Decision | continue, adjust, or stop |

## Success Looks Like

At least one of these should happen:

- owner chases fewer updates
- job photos are easier to find
- estimate/job handoff is cleaner
- field report/proof is easier to review
- follow-up is less likely to be missed
- contractor sees a clear reason to keep using Apex HQ

## Pilot Close Script

```text
The cleanest way to test Apex HQ is not to switch everything. We set up one real workflow, use it for 14 days, and see if it saves enough chasing to be worth continuing.
```

## Founder Pricing Direction

Founder pricing is discussed after interest is real and the contractor size is clear.

Likely options:

- Basic founder plan: around $99/month for solo or very small contractors
- Premium founder plan: around $249/month for growing contractors with crews/jobs to coordinate
- Elite founder support: $750+/month, only if hands-on setup/growth help is needed

Simple pricing answer:

```text
It depends on company size. A solo contractor would likely start around $99/month during the founder pilot. A growing contractor with crews would likely be closer to $249/month. I would rather match the package to what you would actually use instead of overselling you.
```

## Day-3 Check-In Questions

- Did the owner/admin log in?
- Did the field user understand what to do?
- Did one photo, report, or job update happen?
- What still went through text?
- What was confusing?
- What would make this easier?

## Day-10 Value Review Questions

- What did Apex HQ help organize?
- What still felt clunky?
- Did it reduce chasing?
- Would you pay to keep using it?
- Which workflow should be improved next?
- Who else should see this?

## End-Of-Pilot Outcomes

Continue:

- select Basic, Premium, or Elite direction
- confirm next workflow
- schedule onboarding

Adjust:

- narrow workflow
- add training
- fix setup confusion
- retest before charging

Stop:

- document why
- ask for honest feedback
- ask for referral only if appropriate

## Testimonial Ask

Only if value was real:

```text
Can I use one sentence from you about what Apex HQ helped clean up? No hype. Just what changed.
```

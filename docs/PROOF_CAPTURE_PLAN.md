# Apex HQ Proof Capture Plan

Status: active proof system

## Rule

Do not claim proof before it exists.

Capture proof moments as they happen, then ask permission before using anything publicly.

## Proof Stages

### Stage 1: Interest Proof

Signals:

- asks price
- asks for demo
- replies with current workflow
- says a pain is real
- sends referral

### Stage 2: Demo Proof

Signals:

- understands workflow
- says which part would help
- identifies real use case
- agrees to pilot discussion
- gives clear objection

### Stage 3: Pilot Proof

Signals:

- real job or estimate entered
- owner uses system
- field user completes one action
- photo/report proof captured
- follow-up tracked
- contractor says it saved chasing

### Stage 4: Public Proof

Only after:

- value is real
- contractor gives permission
- quote is accurate
- name/logo use is approved separately

## What To Capture

```text
Company:
Person:
Date:
Proof type:
Exact words:
Context:
Permission to use publicly? yes/no
Anonymous use allowed? yes/no
Name/logo allowed? yes/no
Follow-up needed:
```

## Testimonial Ask

Only after value:

```text
Can I use one sentence about what Apex HQ helped clean up? Nothing hype. Just what changed.
```

## Referral Ask

After a helpful conversation:

```text
Who do you know that is good at the work but buried in estimates, texts, photos, or follow-up?
```

After pilot value:

```text
Would you be comfortable introducing me to two contractors who run into the same kind of job tracking or field proof headache?
```

## What Not To Use

- private texts without permission
- screenshots with personal info
- company names without permission
- logos without permission
- edited quotes that change meaning
- implied customer status if they only gave feedback

# Apex HQ Competitive Battlecards

Status: sales talk tracks

## Rule

Do not attack competitors. Position Apex HQ honestly.

## Buildertrend

If they use Buildertrend:

```text
If Buildertrend is working well, keep using it. Apex HQ may fit if your smaller field-to-office workflows still feel too heavy or scattered, especially around estimates, job proof, photos, reports, and follow-up.
```

Where Apex HQ can win:

- simpler contractor command center
- more founder-led setup
- concrete-first credibility

Where Apex HQ is weaker:

- less mature
- fewer broad construction management features

## Procore

Talk track:

```text
Apex HQ is not trying to be Procore for huge enterprise projects. It is for contractors who need practical office-to-field control without enterprise weight.
```

Where Apex HQ can win:

- small/mid contractor fit
- lighter setup
- practical workflow

Where Apex HQ is weaker:

- enterprise controls
- integrations
- maturity

## Jobber / Housecall Pro

Talk track:

```text
Those are strong service business tools. Apex HQ is aimed more at project-based contractors where estimate handoff, job proof, field photos, reports, and change notes matter.
```

Where Apex HQ can win:

- project workflow
- field proof
- contractor/job handoff language

Where Apex HQ is weaker:

- mature payment/service dispatch features

## ServiceTitan

Talk track:

```text
ServiceTitan is powerful for larger service companies. Apex HQ is being built for contractors who want something more practical and focused before they need that level of system.
```

## CompanyCam

Talk track:

```text
CompanyCam is strong for photos. Apex HQ's angle is connecting photos to estimates, jobs, reports, follow-ups, and owner review.
```

## Spreadsheets / Texts

Talk track:

```text
Spreadsheets and texts are flexible, and every contractor uses them. Apex HQ is for the parts they do poorly: field proof, job handoff, photos, reports, and follow-ups in one place.
```

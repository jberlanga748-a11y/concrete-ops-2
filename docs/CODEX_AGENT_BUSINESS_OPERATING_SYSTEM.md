# Apex HQ Codex Agent Business Operating System

Status: active operating model
Purpose: use ChatGPT Pro / Codex agents as much as possible without adding unnecessary paid tools

## Core Decision

Use Codex agents as the main business labor force.

Do not buy paid CRM, SMS automation, cold email automation, social schedulers, ads tools, or extra AI tools until Apex HQ has proof from real demos and pilots.

## What John Should Use Paid For Right Now

Current paid stack should stay lean:

```text
ChatGPT Pro / Codex agents
Namecheap/Gmail business email
Phone
Existing app hosting/infrastructure
Free docs/sheets/forms/calendar tools where possible
```

Everything else waits until the sales motion proves itself.

## What Agents Should Do

Agents should prepare, research, draft, score, organize, and review.

Agents should not send, publish, spend money, or promise anything publicly without John approving it.

## Daily Agent System

### 1. Morning GTM Agent

Runs or prepares:

- daily GTM brief
- top 3 targets
- what changed
- who to call/text
- what to wait on
- risky claims
- exact manual actions for John

Primary docs:

- `AGENT_DAILY_GTM_BRIEF.md`
- `FIRST_10_DEMO_TARGETS.md`
- `OUTREACH_TRACKER.md`
- `PUBLIC_CLAIMS_GUARDRAILS.md`

### 2. Prospect Research Agent

Job:

- research 3 contractor prospects per day
- verify website/public facts
- separate facts from inference
- rank fit
- suggest best pain angle

Output:

- update target notes
- prepare contact strategy
- flag poor fits

Never:

- invent crew count
- invent owner name
- claim they need Apex HQ without evidence

### 3. Sales Draft Agent

Job:

- write first-touch messages
- write follow-ups
- write call openers
- write voicemail scripts
- write reply suggestions

Output:

- drafts ready for John approval

Rules:

- short
- contractor language
- one pain
- one ask
- no hype
- no guaranteed jobs

### 4. Demo Prep Agent

Job:

- prepare demo path for each prospect
- choose solo vs growing contractor route
- prepare discovery questions
- prepare what not to show
- prepare recap template

Primary docs:

- `DEMO_READY_CHECKLIST.md`
- `CONTROLLED_DEMO_MAP.md`
- `DEMO_FEEDBACK_QUESTIONS.md`

### 5. Call Notes Agent

Job:

- turn John's rough call notes into clean CRM notes
- update objection bank
- update follow-up date
- identify pilot fit
- draft follow-up

Input from John:

```text
Company:
What they said:
Pain:
Objection:
Next step:
```

Output:

- tracker update
- next message draft
- learning note

### 6. Customer Success Agent

Job:

- prepare pilot kickoff
- define one workflow
- create day-3 check-in
- create day-10 value review
- track proof moments

Primary docs:

- `PILOT_AGREEMENT_OUTLINE.md`
- `FOUNDER_PILOT_CLOSE_PACKAGE.md`
- `CUSTOMER_SUCCESS_PLAYBOOK.md`
- `PROOF_CAPTURE_PLAN.md`

### 7. Risk And Claims Agent

Job:

- review public copy before sending/posting/publishing
- flag overclaims
- rewrite safer language
- check legal-adjacent/current facts when needed

Primary docs:

- `PUBLIC_CLAIMS_GUARDRAILS.md`
- `RISK_REWARD_MATRIX.md`
- `DO_NOT_BUILD_YET_LIST.md`

### 8. Finance Agent

Job:

- update monthly expense model
- track founder pay rules
- warn if new tools are premature
- track AI/API cost risk
- compare monthly revenue vs expenses

Primary docs:

- `MONTHLY_EXPENSE_MODEL.md`
- `FOUNDER_PAY_REINVESTMENT_PLAN.md`
- `FINANCIAL_MODEL_DIRECTION.md`

## Weekly Agent System

### Monday: Target And Outreach Prep

Agents prepare:

- 10 target priorities
- 5 warm messages
- 5 cold messages
- call sheet

John does:

- send approved messages
- make calls
- log replies

### Tuesday: Demo And Follow-Up Prep

Agents prepare:

- demo route for each interested prospect
- follow-up messages
- objection responses

John does:

- run calls/demos
- record rough notes

### Wednesday: Research And Partner Day

Agents prepare:

- contractor group ideas
- supplier/material yard targets
- GC/subcontractor referral ideas
- local contractor prospects

John does:

- warm relationship outreach
- calls/texts

### Thursday: Pilot And Customer Success Day

Agents prepare:

- pilot setup checklist
- day-3/day-10 scripts
- proof capture plan

John does:

- onboarding calls
- check-ins

### Friday: Review And Repair Day

Agents prepare:

- weekly metrics
- objection summary
- best messaging
- what to stop doing
- next week's target list

John does:

- decide next week's focus
- approve changes

## What John Should Still Do Manually

John should personally handle:

- first calls
- first texts
- first demos
- pricing conversations
- pilot close
- relationship-building
- final approval before anything public

Why:

```text
Founder trust is the advantage right now.
```

Agents make John faster, but John still closes trust.

## What Agents Should Not Do Yet

Do not allow agents to:

- send cold texts
- send cold emails
- post social content
- run ads
- buy tools
- promise features
- promise guaranteed jobs
- speak as if Apex HQ has customers unless true
- negotiate legal terms
- call prospects
- answer customer calls
- make automatic replies

## Best Use Of ChatGPT Pro / Codex

Use it for high-leverage thinking and repetitive business labor:

- turn rough thoughts into clean scripts
- research prospects
- prepare daily briefs
- write follow-ups
- summarize call notes
- maintain docs
- review claims
- make pricing decisions
- create onboarding plans
- turn objections into better messaging

Do not use it as a replacement for:

- customer trust
- legal/accounting advice
- product truth
- real customer proof

## First 30-Day Agent Goal

The goal is not "more documents."

The goal is:

```text
20 qualified contractor conversations
5 guided demos
2 paid pilot candidates
1 paid pilot started
```

Agents should be judged by whether they help create those outcomes.

## Agent Scorecard

Track weekly:

| Metric | Target |
| --- | ---: |
| prospects researched | 15 |
| approved messages drafted | 15 |
| calls prepared | 10 |
| follow-ups drafted | 10 |
| demos prepared | 2-5 |
| objections logged | 5+ |
| risky claims caught | 100% |
| new paid tools avoided | yes |

## When To Add Paid Tools

Add Calendly/Tally/free tools anytime if useful.

Add paid CRM only when:

- tracker becomes hard to manage
- more than 30 active prospects
- follow-ups are slipping

Add SMS automation only when:

- there is proper consent/opt-out handling
- A2P 10DLC setup is understood
- business identity is ready
- manual SMS is proven useful

Add email automation only when:

- manual email converts
- unsubscribe/opt-out process is ready
- cold vs opted-in email is separated

Add paid ads only when:

- demo converts manually
- landing page is clean
- offer is proven
- tracking is set up

## Exact Operating Rule

Every day, agents should answer:

```text
Who should John contact today?
What should he say?
What should he avoid promising?
What should he measure?
What follow-up is due?
What did we learn?
```

That is the business operating system.

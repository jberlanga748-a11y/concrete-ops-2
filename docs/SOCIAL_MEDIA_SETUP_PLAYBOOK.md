# Apex HQ Social Media Setup Playbook

Status: draft for account setup
Use for: creating Apex HQ social profiles, first posts, and founder-led launch content

## Goal

Create social media profiles that make Apex HQ look real, contractor-first, and ready for controlled founder-led demos.

Do not make Apex HQ look like a fully public self-serve SaaS yet.

## Platforms To Create First

Create in this order:

1. LinkedIn Company Page
2. Facebook Business Page
3. YouTube channel
4. Instagram
5. TikTok

Optional later:

- X/Twitter
- Threads
- Google Business Profile, only if Apex HQ has a real service-area/company setup ready

## What Not To Post Yet

Do not post:

- pricing graphics before demo/pilot offer is final
- enterprise claims
- public signup claims
- guaranteed lead claims
- AI autopilot claims
- fake customer testimonials
- fake case studies
- screenshots with messy demo data
- app screenshots showing test records

## Account Setup Checklist

Before posting:

- create company email/login records securely
- use Apex HQ name consistently
- use same handle where possible
- upload logo
- upload cover/header image
- add `apexhq.online`
- add short bio
- add founder-led demo language
- post first intro post
- pin intro post
- save all usernames/passwords somewhere secure

# Apex HQ Controlled Demo Map

Status: required demo route

## Demo Rule

Do not wander.

Show one workflow:

```text
lead/estimate -> job setup -> field handoff -> photo/report proof -> owner review -> follow-up
```

## 15-Minute Demo Route

| Time | Screen | Goal |
| --- | --- | --- |
| 0-2 min | no screen / discovery | ask where leads, estimates, job info, and photos live now |
| 2-4 min | Command Center | show owner visibility |
| 4-6 min | Lead/customer | show where the work starts |
| 6-8 min | Estimate/proposal | show rough notes/estimate direction |
| 8-10 min | Job setup | show handoff from office to work |
| 10-12 min | Schedule / Today's Work / field view | show crew/foreman clarity |
| 12-14 min | Photos/reports/proof | show job proof coming back |
| 14-15 min | recap | ask which part would help most |

## Solo Contractor Path

Use for M2 Mini and owner-operators.

Show:

- lead/customer
- estimate/proposal
- job info
- follow-up
- website lead flow direction
- AI rough notes direction

Avoid:

- multi-crew rollout
- advanced admin
- complex reports
- Elite services

## Growing Contractor Path

Show:

- estimate-to-job handoff
- schedule
- foreman field view
- photos/reports
- owner review
- follow-up

Avoid:

- AI as the main selling point
- every feature
- custom feature discussions

## Screens To Avoid Unless Asked

- billing/packages
- deep settings
- role/security internals
- unfinished automations
- anything with test/junk data
- anything requiring a long apology

## Demo Close

If fit is real:

```text
I would not start by switching everything. I would test one workflow for 14 days and see if it saves enough chasing to keep using.
```

If fit is weak:

```text
That helps. I do not think I should push you into a pilot yet. I will keep improving the workflow and check back when it fits better.
```

## Allowed Pilot Workflow

Choose one:

- Lead or opportunity intake -> estimate/proposal -> follow-up
- Approved estimate -> job -> schedule -> field handoff
- Job -> field photo/report/upload -> owner review
- Field proof -> ready-to-bill review

Do not expand the pilot into payroll, accounting, public signup, payments, automatic customer messaging, or guaranteed lead generation.

## Day 0 Setup

- Confirm this is a guided beta, not a public launch.
- Confirm the pilot environment does not contain unrelated demo/customer data.
- Confirm owner/admin can log in.
- Confirm field user can log in only if the field workflow is in scope.
- Confirm field users cannot access estimates, pricing, owner/admin settings, package controls, or billing surfaces.
- Enter one real lead, estimate, job, or proof record.
- Confirm the first action the contractor will perform.
- Confirm support channel and response expectations.
- Schedule Day 3 check-in.
- Schedule Day 10 value review.

## Demo Script

1. Open Command Center and show what needs attention.
2. Open the selected workflow record.
3. Show estimate/job/proof context.
4. Show the field action on phone if field workflow is in scope.
5. Show Support intake for feedback or blockers.
6. Confirm what the user will try before Day 3.

## Day 3 Check-In

- Did owner/admin log in?
- Did field user complete the agreed action?
- What still happened through text, calls, or memory?
- What confused the owner/admin?
- What confused the field user?
- Is the selected workflow still the right workflow?
- Is there a real blocker or only training friction?

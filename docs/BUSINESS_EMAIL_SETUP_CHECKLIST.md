# Apex HQ Business Email Setup Checklist

Status: prep checklist only

## Goal

Set up a business email that is trusted enough for founder-led contractor outreach.

## Recommended Inbox

Use a simple sender identity:

- `john@apexhq.online`
- `hello@apexhq.online`
- `founder@apexhq.online`

Best first choice:

- `john@apexhq.online`

Why:

- feels personal
- better for founder-led outreach
- less corporate
- easier for contractors to reply to

## Required Setup Before Sending

- buy or confirm Apex HQ domain
- set up business email inbox
- set display name to `John | Apex HQ` or `John from Apex HQ`
- add signature
- add business phone if available
- add calendar/demo booking link if ready
- test send to personal inbox
- test reply handling
- confirm email works on phone

## Deliverability Basics

Configure these on the domain/email provider:

- SPF
- DKIM
- DMARC

Recommended DMARC starting posture:

```text
p=none
```

Move stricter only after sending is stable.

## Warm-Up Rule

Do not blast the first 20 on the first hour.

First week:

- send 5 to 10 personalized emails per day
- manually write or review each one
- mix email with calls and direct follow-up
- do not automate sequences yet

```text
John

apexhq.online
```

## First Test Email

Send this to yourself first:

```text
Subject: Apex HQ email test

Testing the new Apex HQ business email, signature, replies, and mobile inbox.
```

Check:

- sender name looks right
- signature looks clean
- reply goes to correct inbox
- message does not land in spam
- links work

## Sending Tools

Start manual.

Do not use:

- personal Gmail
- automated cold email tools
- bulk sends
- scraped lists without review
- AI auto-send

Acceptable early process:

- manual email from business inbox
- manual call
- manual SMS from approved business phone
- tracker updated by hand

## Business Email Launch Decision

Ready when:

- inbox is working
- sender identity is clean
- SPF/DKIM/DMARC are configured
- demo times are ready
- first 20 drafts are reviewed
- tracker is ready
- no one is relying on personal Gmail

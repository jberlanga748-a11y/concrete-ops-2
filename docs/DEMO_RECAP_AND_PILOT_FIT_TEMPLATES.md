## Pilot Fit Scorecard

Score each item 0 to 2.

| Signal | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Real workflow pain | vague curiosity | some pain | clear repeated pain |
| Owner/admin buy-in | not engaged | interested | willing to test |
| Field workflow need | none | possible | clear crew/proof need |
| First workflow clarity | unclear | one likely workflow | exact workflow named |
| Current process scattered | not really | somewhat | texts/photos/paper/spreadsheets |
| Ability to start | no time | maybe | can schedule kickoff |
| Fit with current product | weak | partial | strong without custom build |
| Pricing openness | rejected | unsure | accepts founder range if value appears |

Pilot fit:

- 13-16: strong pilot candidate
- 9-12: nurture or run a second focused demo
- 5-8: feedback only
- 0-4: not a fit now

For strong pilot candidates, move to `docs/PILOT_KICKOFF_AND_CHECKIN_TEMPLATES.md` before scheduling kickoff so success criteria, support expectations, and day-3/day-10 decision points are explicit.

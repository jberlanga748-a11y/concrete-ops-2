## Churn Impact

If MRR is $20,000:

| Monthly Churn | MRR Lost |
| ---: | ---: |
| 2% | $400 |
| 5% | $1,000 |
| 8% | $1,600 |

Retention matters as much as acquisition.

## Forecast Rule

Do not forecast from hopes.

Forecast from:

- actual reply rates
- actual demo rates
- actual pilot conversion
- actual paid conversion
- actual churn

# Apex HQ Outreach Tracker

Status: working sales tracker
Sending: manual only until business email/texting tools are approved

## Tracker Rules

- Update this after every call, email, text, voicemail, demo, or referral.
- Do not mark a message as sent unless a human actually sent it.
- Stop follow-up sequences when someone replies.
- Mark `Do Not Contact` immediately if requested.
- Keep notes plain and factual.

## Status Values

- Not Started
- Ready for Outreach
- Contacted - Email
- Contacted - SMS
- Contacted - Call
- Left Voicemail
- Replied
- Demo Scheduled
- Demo Completed
- Pilot Offered
- Pilot Accepted
- Nurture
- Not a Fit
- Do Not Contact

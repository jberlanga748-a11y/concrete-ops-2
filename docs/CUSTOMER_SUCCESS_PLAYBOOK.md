# Apex HQ Customer Success Playbook

## Customer Success Goal

Help a contractor get one real workflow working before trying to roll out everything.

First success should be simple:

- first company setup complete
- first estimate or job entered
- first crew/field user understands their role
- first photo/report/proof submitted
- owner sees less chasing

## Onboarding Flow

Step 1: Fit check.

- trade
- crew count
- current tools
- biggest pain
- pilot workflow
- owner/admin contact
- field lead contact

Step 2: Setup call.

- company name and basic info
- users and roles
- one customer or lead
- one estimate or job
- one crew/foreman
- one field action

Step 3: First workflow setup.

- create or review first customer
- create or review first estimate/job
- assign crew
- show field user what to do
- define what proof is required

Step 4: Day-3 check-in.

- did the field user log in?
- did a photo/report get submitted?
- what confused the owner?
- what confused the crew?
- what still lives in texts?

Step 5: Day-10 value review.

- what did Apex HQ clean up?
- what still needs work?
- would they pay for this?
- which package fits?
- who can they refer?

## Week 1 Success Plan

Day 0:

- kickoff completed
- users created
- first workflow selected
- success criteria written in plain language

Day 1:

- owner/admin logs in
- first customer/lead reviewed
- first job or estimate reviewed

Day 2:

- field user logs in
- field action practiced
- photo/report workflow tested

Day 3:

- feedback call
- remove friction
- confirm real job for pilot use

Day 5:

- check if proof/report/follow-up happened
- capture first useful quote or complaint

Day 7:

- review what changed
- decide whether pilot is on track

## First Job Setup Plan

- choose one real job
- confirm customer/project name
- confirm site/address
- confirm crew/foreman
- add scope notes
- add required photos/proof
- add report expectation
- show owner review path

## First Estimate Setup Plan

- choose one active estimate
- add customer/project
- add rough scope
- add line items or estimate details where available
- add exclusions/assumptions if needed
- define follow-up date
- define what would make it ready to convert to job

## First Crew Setup Plan

- add only the users needed for the pilot
- keep roles clean
- field users should only see field-safe work
- explain the one action they must complete
- do not overload crews with office workflows

## Support Workflow

Every issue should capture:

- company/workspace
- user name
- user role
- page/workflow
- device/browser if known
- exact steps
- screenshot if possible
- expected result
- actual result
- blocking yes/no
- severity

Severity:

- P0: security, company data, role leakage, login down
- P1: pilot-blocking workflow failure
- P2: important friction with workaround
- P3: minor polish, copy, or training issue

## Feedback Workflow

Ask:

- What were you trying to do?
- Where did you hesitate?
- What did you still do by text?
- What would make this worth paying for?
- What should not be built yet?

Log feedback as:

- sales objection
- onboarding friction
- field usability issue
- missing workflow
- product roadmap idea
- support/training issue

## Testimonial Workflow

Only ask after value is real.

Prompt:

"What did Apex HQ help you stop chasing or keep better organized?"

Good formats:

- one-sentence quote
- short before/after story
- anonymous case note
- permission-based logo/name later

## Churn Prevention Plan

Watch for:

- owner stops logging in
- field users never adopt
- first job is not set up
- no photos/reports submitted
- customer expects features that are not built
- setup takes too long
- support questions repeat

Actions:

- narrow the workflow
- schedule a short reset call
- remove users/features not needed for pilot
- restate the value goal
- document missing product needs honestly
- do not promise custom features to save a weak-fit customer

## Customer Success Metrics

| Metric | Target |
| --- | --- |
| Time to first setup | Same day as kickoff |
| Time to first field action | Within 3 days |
| Day-3 check-in completed | 90%+ |
| Pilot workflow completed | 70%+ |
| Paid conversion from qualified pilots | 30% to 50% early target |
| Referral ask completed | 100% of successful pilots |

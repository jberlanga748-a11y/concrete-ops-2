# Apex HQ Fencing Pilot Decision

Status: business decision draft  
Source: builder/user readiness audit provided May 20, 2026  
Use for: deciding how to handle the first friendly fencing contractor

## Decision

Apex HQ can move forward with a friendly fencing contractor as a guided pilot candidate.

Do not treat this as public launch.

```text
Guided demo: GO
Friendly controlled pilot: GO, with supervision
Public launch: NO-GO
Production deploy: NO-GO unless explicitly approved through backup-first release process
```

## Positioning

Use:

```text
Apex HQ is ready for a guided founder-led pilot around one fencing workflow.
```

Do not say:

- fully public SaaS
- production system of record
- guaranteed leads
- guaranteed revenue
- AI finds/bids jobs automatically
- no setup needed

## Strongest Workflow

```text
Lead / Opportunity -> Estimate -> Job -> Schedule -> Field Proof -> Report / Upload -> Ready-to-Bill review
```

## Best First User Profile

Good fit:

- friendly fencing contractor
- owner/operator or small office/admin team
- 3 employees or small crew
- trying to grow
- willing to give feedback
- has active estimates/jobs/photos/reports to test
- accepts guided setup

Poor fit:

- wants guaranteed lead generation
- wants accounting/payments immediately
- expects fully autonomous job-finding
- needs guaranteed uptime from day one
- wants full self-serve onboarding

## Business Questions Answered

### Who is the safest first fencing pilot user?

The safest first pilot is the friendly fencing company already in conversation, if the owner understands this is a guided pilot and agrees to one workflow.

### Free pilot, paid beta, or demo-only walkthrough?

Recommended path:

1. free or no-risk guided walkthrough
2. 3-5 day guided validation
3. convert to paid founder pilot if value is clear

If website management is included:

```text
$400/month = website management only
$649/month = website management + Apex HQ guided founder pilot
$750+/month = website management + Apex HQ + hands-on growth/setup support
```

### What promise are we making?

Safe promise:

```text
We will help test whether Apex HQ can organize one fencing workflow: lead, estimate, job, schedule, field proof, report/upload, and owner review.
```

Do not promise:

- more jobs
- $1M revenue
- automatic bidding
- automatic outreach
- full operations replacement

### What workflows are out of scope?

Out of scope:

- accounting/payroll
- payments
- automated SMS/email sending
- ad management
- full customer portal
- automatic job sourcing
- AI bidding/pricing/sending
- custom fencing feature builds
- full company migration

### What support response time can be provided?

During the first friendly pilot:

```text
Same-day best-effort support during agreed working hours.
Urgent blockers get priority.
No 24/7 support promise.
```

### Do we need terms/privacy before outside login?

Yes, before any real paid or ongoing outside use.

For the first friendly guided validation, use plain written pilot expectations at minimum:

- guided beta/pilot
- one workflow only
- do not upload sensitive data not needed for testing
- no guaranteed uptime
- no guaranteed leads/revenue
- no public testimonial/logo without permission

### Should estimate branding polish be finished before first live demo?

For a guided walkthrough:

```text
Recommended but not absolutely required if John controls the route.
```

For a paid pilot or proposal-heavy user:

```text
Yes, finish estimate branding polish first or avoid relying on estimate output as the main value proof.
```

## 3-5 Day Guided Pilot Scope

Test only:

1. Add or import a lead/opportunity.
2. Create or review an estimate.
3. Move work into job/schedule.
4. Use field phone flow for photos/reports/uploads.
5. Review proof in office.
6. Capture feedback through Support or notes.
7. Keep their current system as backup.

## Success Criteria

The pilot is successful if:

- owner/admin understands the workflow
- one field employee can complete one action
- estimate/proposal experience feels credible enough
- field photo/report flow feels useful
- owner sees value in Command Center or review flow
- no role/permission failures occur
- no major performance issue blocks the workflow
- user asks to keep using it or wants a paid founder pilot

## First Message To Send

```text
I can set you up, but I want to do it the right way.

Apex HQ is ready for a guided pilot, not a full self-serve rollout yet. I would start with one fencing workflow for 3-5 days: lead/opportunity, estimate, job schedule, field photos, report/upload, and owner review.

You would still keep your current system as backup while we test it. If the workflow feels useful, then we can turn it into a 14-day founder pilot and decide if it makes sense to keep going monthly.

For website management alone, we can do $400/month. If we include Apex HQ with website management and workflow setup, I would put that at $649/month during the founder stage.
```

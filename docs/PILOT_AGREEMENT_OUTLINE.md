# Apex HQ Founder Pilot Agreement Outline

Status: plain-language business outline, not legal advice

## Purpose

Use this to explain pilot terms before someone starts using Apex HQ.

This is not a formal legal contract. Get professional legal help before relying on it as a binding agreement.

## Pilot Summary

Apex HQ founder pilot is a guided test of one contractor workflow.

## Pilot Length

Default:

- 14 days

Extend to 30 days only if the contractor is engaged and the workflow needs more time.

## Pilot Workflow

Choose one:

- lead/estimate follow-up
- estimate-to-job setup
- job-to-field handoff
- photo/report proof
- owner review and missing items

## Included

- setup/kickoff call
- one selected workflow
- owner/admin setup
- one field user if needed
- day-3 check-in
- day-10 value review
- end-of-pilot decision
- founder pricing option if value is real

## Not Included

- guaranteed leads
- guaranteed sales
- ad management
- accounting/payroll replacement
- full company migration
- custom feature build
- automatic sending without review
- AI pricing/approving/sending without review
- enterprise rollout
- unlimited support

## Customer Responsibilities

- provide one owner/admin contact
- provide one real workflow to test
- attend kickoff
- participate in day-3 and day-10 reviews
- give honest feedback
- avoid uploading sensitive data not needed for pilot

## Pricing After Pilot

- Basic: around $99/month
- Premium: around $249/month
- Elite support: $750+/month only when support and value justify it

## Proof And Testimonials

No public testimonial, logo, case study, or quote may be used unless the contractor gives permission.

# Sunday First Customer Call Script

Status: founder sales script for first paid customer conversation

Use this as a talk track. Do not read it like a robot. Keep it calm and direct.

## Opening

```text
Alright, so I want to explain this the right way before we get started Sunday.

Since you want the website and Apex HQ together, I would not treat this like just basic website management. This is more of a full operating setup for your fence company.
```

## Explain The Package

```text
I would set you up on what I am calling the Apex HQ Fence Growth Package.

That includes the website management, Apex HQ access, the AI tools, the fence measuring tool, lead and estimate workflow, jobs, schedule, crew handoff, photos and proof, reports, change order review, owner review, employee setup, and time/payroll prep.

The website build itself would be $1,000.

Then the website management plus Apex HQ package would be $999/month.

Since you are coming in early, I will waive the normal setup and onboarding fee for the first month.
```

## Explain Why It Costs That

```text
The reason I am pricing it there is because if you tried to piece this together with separate tools, you could easily be over a thousand a month before setup and support.

You would need something for leads, estimates, jobs, scheduling, photos, measuring, payroll/time review, website updates, and support.

This puts all of that into one package, and you get me helping you set it up around how your company actually works.
```

## Explain The Goal

```text
The goal is not to throw a bunch of software at you.

The goal is to help you look more professional, follow up faster, keep jobs organized, give your employees a cleaner workflow, and help you handle more work without everything living in texts, paper, and memory.

The main workflow we are going to set up is:

lead to estimate, estimate to job, job to schedule, field proof, change order if needed, closeout, and owner review.
```

## AI Boundary

```text
The AI side is a big part of it, but I want to explain it clean.

The AI can help draft, organize, score, flag, and prepare things. It can help with leads, estimates, follow-ups, job setup, reminders, and owner review.

But for important stuff, I still want it review-first. So anything that gets sent, priced, scheduled, billed, or changed should still be reviewed before it goes out.
```

## Fence Measuring Boundary

```text
The fence measuring tool uses satellite view to help with rough takeoffs and first looks.

That can save time before you drive out or before you start building an estimate.

But final measurements should still be verified onsite before contract, ordering, or install.
```

## Payroll Boundary

```text
The payroll side is more payroll prep and time review.

Apex HQ can help track time, organize hours, and prepare review. But final payroll, taxes, filings, payments, workers comp, and compliance should still go through your payroll provider, accountant, or normal business process.
```

## Website Boundary

```text
The website management covers normal monthly updates, photos, project updates, service edits, contact form checks, and keeping the lead flow cleaner.

Big redesigns, paid ads, major SEO campaigns, big custom pages, or heavy content work would be separate.
```

## If He Says It Is Expensive

```text
I get it. If this was only website management, I could keep it closer to $400/month.

But this is not just website management.

This is the website, the app, AI, measuring, lead and estimate workflow, job tracking, employee setup, payroll prep, and me helping you dial it in.

I do not want to underprice it and then not be able to support it the right way.
```

Then say:

```text
What I can do is make the website build easier.

Instead of the full $1,000 up front, we can do $500 down and split the other $500 over the next two months.

But I would keep the monthly package at $999 because that is the actual operating package.
```

## If He Wants A Cheaper Option

```text
The cheaper option would be website management only at $400/month.

But that would not include the full Apex HQ package, AI, measuring, employee setup, or payroll prep.

Based on what you told me about wanting to grow, I think the full package makes more sense to test for 30 days.
```

## First 30 Days

```text
For the first 30 days, I would keep it simple.

Week one, we set up the company, employees, website lead flow, and one real lead-estimate-job workflow.

Week two, we use it on active work and test the measuring, follow-up, photos, reports, and time tracking.

Week three, we clean up anything confusing and tighten the estimate-to-job handoff.

Week four, we review what actually helped and decide what to keep improving.
```

## No Overpromise

```text
I do not want to promise guaranteed leads or say this alone gets you to a million dollars.

What I can say is this is built to help you operate cleaner, follow up better, track the work better, and look more professional while you grow.
```

## Close

```text
If that works for you, I can send the invoice for the website build and the first month.

Then Sunday we can get your company set up and start with the first real workflow.
```

## Short Version If You Get Nervous

```text
For everything you want - the website, Apex HQ, AI, fence measuring, job workflow, employee setup, payroll prep, and direct support - I would do $999/month.

The website build itself is $1,000, but I can split that with $500 down and the rest over the next two months.

I will waive the normal setup fee since you are coming in early.

I am not promising guaranteed leads or a million-dollar result, but the goal is to help you run cleaner, follow up faster, and handle more work without everything being scattered.
```

# Apex HQ Sales Operating System

Status: founder-led sales process

## Sales Principle

Do not try to sell the whole platform in the first conversation.

Sell the next step:

```text
20-minute walkthrough -> 14-day pilot -> paid founder plan
```

## Pipeline Stages

| Stage | Meaning | Exit Criteria |
| --- | --- | --- |
| Target | company looks like a fit | added to tracker |
| Contacted | first email/text/call made | touch logged |
| Replied | contractor responded | pain/interest captured |
| Demo Scheduled | walkthrough booked | calendar set |
| Demo Completed | walkthrough happened | fit/no-fit noted |
| Pilot Offered | one workflow proposed | pilot terms sent |
| Pilot Accepted | contractor agrees to test | kickoff scheduled |
| Active Pilot | workflow being tested | day-3 check-in completed |
| Paid Customer | continues after pilot | package selected |
| Nurture | not now but possible later | next check-in date |
| Closed Lost | not a fit | reason logged |

## Daily Sales Blocks

Minimum useful day:

- 5 outbound touches
- 3 calls
- tracker updated
- follow-ups sent or drafted

Strong day:

- 10 outbound touches
- 5 calls
- 1 demo booked
- 1 referral ask
- 1 useful objection logged

## Weekly Targets

| Metric | Target |
| --- | ---: |
| New outbound touches | 25-50 |

| Conversations | 5-10 |
| Demos booked | 2-5 |
| Pilots offered | 1-3 |
| Pilots accepted | 1 |
| Referral names | 3-5 |

## Qualification Score

Score each company 1-5.

5:

- active jobs
- field crews
- estimate/job/photo/report pain
- owner/admin engaged
- willing to try pilot

4:

- likely pain
- reachable
- good trade fit
- needs demo to confirm

3:

- possible fit but unclear pain

2:

- poor timing or weak workflow fit

1:

- not a fit

## Demo Qualification Questions

- Do they have active jobs or estimates?
- Do they have field users?
- Does the owner chase updates?
- Are photos/reports/follow-ups scattered?
- Is there one workflow they will test?
- Can they attend day-3 and day-10 check-ins?

## Objection Log

Track objections exactly as said.

Categories:

- already has software
- no time
- price
- crew adoption
- wants accounting/payroll
- wants lead generation
- not ready
- needs owner approval
- skeptical of software

## Follow-Up Rules

- follow up within 24 hours after any live conversation
- send demo recap same day
- send pilot terms only after a real fit is confirmed
- stop if they say no
- ask for referral on warm no

## Founder Weekly Review

Every Friday, answer:

- How many calls did I make?
- How many replies did I get?
- What pain came up most?
- What objection came up most?
- Which message got the best response?
- Which target type looked strongest?
- What should change next week?

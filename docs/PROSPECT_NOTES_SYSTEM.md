# Apex HQ Prospect Notes System

Status: required for every call, text, email, demo, and pilot conversation

## Rule

If it is not written down, the business cannot learn from it.

## Where Notes Go

Primary tracker:

```text
docs/OUTREACH_TRACKER.md
```

Daily call prep:

```text
docs/DAILY_OUTREACH_CALL_SHEET.md
```

Daily action brief:

```text
docs/AGENT_DAILY_GTM_BRIEF.md
```

## Fit Score

Score 1 to 5.

| Factor | Score |
| --- | --- |
| owner-led |  |
| active estimates/jobs |  |
| scattered workflow |  |
| reachable decision maker |  |
| willing to test one workflow |  |
| can pay $99-$249/month |  |
| support burden manageable |  |

30+ = contact now.
24-29 = good target.
18-23 = research more.
Below 18 = later or skip.

## Exact Words To Capture

Save phrases like:

- "I hand write them out."
- "I use Wix."
- "My guys text me everything."
- "Photos are all over."
- "I forget to follow up."
- "How much does it cost?"

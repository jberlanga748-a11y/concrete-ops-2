## Pass Standard

Ready for M2 Mini:

- solo workflow is clean
- no junk visible
- pricing answer ready

Ready for warm demos:

- owner/admin path clean
- one field path clean
- follow-up path clean

Ready for cold demos:

- demo path repeatable
- first 5 warm walkthroughs do not expose major confusion

Ready for paid pilot:

- one workflow can be set up with real data
- day-3 and day-10 support plan ready
- no major role/security confusion

## Go / No-Go

Go if a contractor can understand one useful workflow in 15 minutes.

No-go if junk data, confusing records, or unsupported AI/pricing expectations are visible.

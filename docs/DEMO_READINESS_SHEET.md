# Apex HQ Demo Readiness Sheet

Status: business/demo prep
Use before: calls, walkthroughs, founder pilot conversations

## Demo Goal

Show Apex HQ as a practical contractor command center.

The point is not to show every feature. The point is to make a contractor say:

"That would help me keep estimates, jobs, photos, reports, and follow-ups from getting scattered."

## Current Product Status

Apex HQ is close to guided-demo ready. Core contractor operations workflows are built and working enough for founder-led walkthroughs:

- Dashboard / Command Center
- Leads
- Customers
- Estimates
- Jobs
- Schedule / Today's Work
- Notifications / reminders
- Daily reports
- Uploads / photo evidence
- Delivery tickets
- Pre-pour / post-pour
- Safety / incidents
- Tool checklist
- Employees / roles
- Field workflows for foreman/employee use
- Role protection blocking field users from office/admin/pricing areas
- AI Rough Notes / estimate helper foundation

Use this status carefully:

- guided founder-led demos: close to ready / usable now
- paid pilot: needs guided setup and a narrow workflow
- public self-serve SaaS: not ready yet

## Demo Positioning

Say:

```text
Apex HQ is a contractor operations platform entering a controlled founder-led demo and pilot phase. The cleanest pilot is one workflow: estimate or job setup, crew/field handoff, photos or report, and owner review.
```

Say:

```text
We are opening a small founder pilot, so I am being direct about what is ready, what is being tested, and what should come later.
```

Do not say:

- "This replaces everything."
- "This is fully automated."
- "AI will run it for you."
- "We guarantee more leads."
- "It is enterprise-ready."
- "It requires no setup."
- "We can build whatever you want."

## What To Show

Show only safe, practical workflows:

1. Lead or customer record.
2. Estimate or job context.
3. Schedule or today's work.
4. Job details.
5. Crew/field view.
6. Photo/report/proof workflow.
7. Ticket, pre-pour/post-pour, safety, or tool checklist only if relevant.
8. Owner/admin review.
9. Follow-up or next-action direction.
10. Founder pilot offer.

## What Not To Show Unless Asked

- deep settings
- unfinished package/billing areas
- admin/security internals
- anything that looks like automatic sending
- anything that suggests AI can act without approval
- production customer data
- roadmap-only future features as if they are live

## What To Say If They Ask "Is This Ready?"

```text
It is pilot-grade. That means we are not opening it wide to every contractor yet. We are bringing in a small group of founder pilots, setting up one real workflow, and making sure it actually helps before we scale it.
```

## What To Say If They Ask "What Does The Pilot Include?"

```text
The pilot is simple. We set up one real workflow, usually estimate-to-job or job-to-field-proof. You test it for 14 days, we check in after day 3, and then we decide if it is worth continuing.
```

## What To Say If They Ask "How Much?"

```text
For the founder pilot, I want to make sure the workflow fits before I push pricing. If it does fit, the likely founder plan is around $249/month for Premium after the pilot, with setup help included during the founder period.
```

If they are very small:

```text
If Premium is more than you need, Basic would likely be closer to $99/month after the pilot.
```

If they want hands-on growth/setup:

```text
If you want more hands-on setup, templates, training, and growth help, that is more of an Elite setup. I would only recommend that if the first workflow clearly proves useful.
```

## What To Say If They Use Another Tool

```text
That is fine. I am not asking you to throw out what works. What I would look for is where things still get messy: estimate handoff, job photos, reports, field proof, or follow-ups. If Apex HQ does not help there, it is probably not the right fit.
```

## What To Say If They Ask About QuickBooks/Accounting

```text
Apex HQ is not trying to replace QuickBooks right now. The focus is getting the job organized before billing: estimate details, job proof, photos, reports, change notes, and follow-up.
```

## What To Say If They Ask About AI

```text
The AI direction is review-first. It can help draft or organize work, but it should not send, price, approve, or promise anything without a human reviewing it.
```

## What To Say If They Ask About Texting/Email Automation

```text
Automatic sending is not the first pilot promise. The safe version is drafts, reminders, and follow-up tracking with a human staying in control.
```

## Discovery Questions Before Screen Share

Ask 3 to 5:

- Where do most of your leads come from?
- How do you track estimates that need follow-up?
- What gets messy between estimate approval and the crew starting?
- Where do job photos usually live?
- Who turns in daily reports or proof?
- What does the owner have to chase every week?
- What would make this worth testing for 14 days?

## 20-Minute Demo Flow

| Time | Action |
| --- | --- |
| 0-3 min | Ask discovery questions |
| 3-5 min | Explain contractor command center |
| 5-8 min | Show lead/customer and estimate/job |
| 8-12 min | Show crew/field proof flow |
| 12-15 min | Show owner/admin review |
| 15-18 min | Ask which part would help most |
| 18-20 min | Offer 14-day pilot if fit is real |

## 15-Minute Guided Demo Flow

| Time | Action |
| --- | --- |
| 0-2 min | Set frame: contractor operations, not public self-serve SaaS |
| 2-4 min | Ask where leads, estimates, job info, and photos live now |
| 4-7 min | Show Command Center, leads, customers, estimates, jobs |
| 7-10 min | Show job, schedule/today's work, and field role view |
| 10-12 min | Show photo/report/proof workflow and relevant ticket/safety/checklist item |
| 12-14 min | Ask which part would save the most chasing |
| 14-15 min | Offer one-workflow pilot only if fit is clear |

## Pilot Close

```text
I would not try to switch your whole company at once. I would set up one real workflow, test it for 14 days, check in after day 3, and see if it actually saves you chasing. If it does, we talk founder pricing. If not, we learned quickly and kept it clean.
```

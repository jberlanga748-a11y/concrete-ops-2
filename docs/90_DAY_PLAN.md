# Apex HQ 90-Day Plan

## Days 1-30: Stabilize And Coordinate

Goals:

- keep pilot workflows stable
- organize agent system and docs
- support first real pilot workflow
- harden company separation plan
- avoid random redesign loops
- book first demos for founding contractor pilots

Key work:

- Master Coordinator docs
- public SaaS safety audit refresh
- company isolation hardening plan
- package entitlement plan
- pilot feedback collection
- app health plan
- pricing/package strategy
- outreach scripts
- demo playbook

## Days 31-60: SaaS Foundation

Goals:

- prepare for more contractor workspaces
- reduce manual setup risk
- clarify packages
- improve onboarding
- convert first 3 to 5 paid pilots if value is proven

Key work:

- public signup/workspace foundation
- first owner onboarding
- invite/activation/password reset
- package entitlement foundation
- company branding/setup defaults
- support/bug report flow
- customer success workflow
- referral/testimonial collection
- first case story from real value

## Days 61-90: Growth And Premium Workflow

Goals:

- make Apex HQ easier to sell
- increase day-one value
- build toward Premium/Elite differentiation
- create repeatable path from demo to pilot to paid

Key work:

- Customer Communication Center
- Watchtower Phase 1
- Operations Command refinement
- Estimate Studio expansion
- Rate Book / Cost Library foundation
- launch/sales materials
- first 100 customer channel testing
- supplier/material yard referral conversations
- local group and LinkedIn content rhythm

## 90-Day Success Metrics

- one pilot completes real office-to-field workflow
- no field permission leaks
- new workspace setup path is safer
- first package structure is documented/partially implemented
- one clear demo script exists
- one founding contractor offer exists
- known risks are tracked
- next 3 phases are obvious
- 20 to 30 demos booked
- 10 pilots started
- 3 to 5 paid conversions from qualified pilots
- 2 to 3 testimonials or short quotes collected
- 15 to 20 referral names collected

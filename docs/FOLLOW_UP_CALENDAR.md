# Apex HQ Follow-Up Calendar

Status: active manual follow-up system

## Rule

Most sales will come from follow-up.

Every contact needs a next date.

## Standard Follow-Up Timing

| Timing | Action |
| --- | --- |
| Day 0 | first touch |
| Day 1 | short follow-up if no reply |
| Day 3 | pain-based follow-up |
| Day 7 | close-the-loop |
| After reply | stop sequence and respond personally |
| After demo | same-day recap |
| Day 3 of pilot | check-in |
| Day 10 of pilot | value review |

## Day 0 First Touch

```text
Hey [Name], this is John with Apex HQ. I have 15 years in concrete and I am building a contractor operations platform to help keep leads, estimates, jobs, photos, reports, and follow-ups organized in one place.

Would a quick guided walkthrough be worth looking at?
```

## Day 1 Follow-Up

```text
Just following up. I am keeping the first walkthrough simple: lead/estimate to job, field handoff, photo/report proof, and owner review.
```

## Day 3 Follow-Up

```text
The main thing I am trying to solve is all the job info getting split between texts, photos, paper, and memory. If that is already clean for you, no worries.
```

## Day 7 Close-The-Loop

```text
Should I close the loop on showing you Apex HQ for now? No pressure either way. I am just keeping the first demo group small.
```

## After Interested Reply

```text
Sounds good. I am keeping these guided and simple. The walkthrough takes about 15 to 20 minutes.

Does [time option 1] or [time option 2] work better?
```

## After Demo Recap

```text
Thanks for taking a look at Apex HQ. My notes were:

- Current setup: [tools]
- Biggest pain: [pain]
- Best workflow to test: [workflow]
- Possible plan: [Basic/Premium/later]

The next step, if you want to test it, would be a 14-day founder pilot around that one workflow.
```

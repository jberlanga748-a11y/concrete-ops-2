# Apex Agent Email Send Gate Decision Packet

Status: proposed boundary only. Not approved for implementation or unlock.

Purpose: define the first candidate external gate for a future review-first Apex Agent email send. This packet does not enable customer contact, does not add provider code, and does not approve production use.

## Candidate Boundary

- Gate: `email_send`
- Workflow: send one already-human-approved estimate follow-up email from the normal Communications or Estimate workflow.
- Actor: owner/admin only.
- Recipient class: one existing lead/customer contact already visible to the current company.
- Content source: a reviewed draft packet generated by Apex Agent and approved by the user immediately before send.
- Send mode: disabled until a separate explicit approval names the provider, template scope, sender identity, test path, rollback path, and verification commands.

## Required Approval Before Any Code Unlock

The user must explicitly approve all of the following in one future work request:

- Exact provider and environment, such as sandbox-only SendGrid or existing configured email service.
- Exact sender identity and allowed recipient class.
- Exact template or draft shape.
- Exact human confirmation UI and copy.
- Exact idempotency key.
- Exact audit event and fields.
- Exact rollback/disable switch.
- Exact tests, including negative role tests and no-send tests.

## Must Stay Locked

- Bulk email.
- SMS.
- Payment collection.
- Bid submission.
- Customer portal writes.
- Scheduling or crew assignment.
- Integration writes.
- Any production data/config/secrets work.

## Verification Required If Later Approved

- Server authorization proves field users cannot send.
- Tenant/company scoping proves cross-company recipients are rejected.
- Human approval is required in the same session before send.
- Idempotency prevents duplicate sends.
- Audit records the actor, target, recipient class, template id, and result without storing secrets.
- Failure state is visible and does not mark follow-up complete.
- Browser smoke covers admin desktop and employee denial.

## Current Decision

Keep email sending locked. Continue using Apex Agent for internal draft/prep packets and human review only.

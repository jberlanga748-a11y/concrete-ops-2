# Apex HQ Founder Daily 12-Hour Schedule

Status: aggressive operating schedule

## Daily Rule

Do not end the day without one concrete business advance:

- conversation
- demo
- pilot
- customer
- referral
- testimonial
- pricing learning
- retention win

## Standard Day

### Block 1: 60 Minutes - Morning Command

Tasks:

- review `CEO_DASHBOARD.md`
- review today's call sheet
- pick top 5 targets
- check follow-ups due
- write daily goal

Output:

- today's target list
- today's must-win action

### Block 2: 3 Hours - Calls And First Touches

Tasks:

- call priority targets
- send manual texts where appropriate
- send manual emails once business email is ready
- leave voicemails
- update tracker immediately

Output:

- conversations
- demos booked
- clear no/next step

### Block 3: 90 Minutes - Follow-Ups

Tasks:

- send follow-ups from live conversations
- send demo booking replies
- send recap notes
- ask warm leads for referrals

Output:

- no loose ends from calls

### Block 4: 2 Hours - Demos Or Demo Prep

Tasks:

- run walkthroughs
- prep demo environment
- practice demo script
- improve demo based on objections

Output:

- demos completed or demo readiness improved

### Block 5: 2 Hours - Pilots And Customer Success

Tasks:

- pilot setup
- day-3 check-ins
- day-10 reviews
- customer support notes
- onboarding cleanup

Output:

- active pilots moving forward
- churn risk reduced

### Block 6: 1 Hour - Partner/Channel Work

Tasks:

- call suppliers/material yards
- message GCs/subcontractors
- post/comment in contractor groups
- LinkedIn outreach

Output:

- referral names
- partner conversations

### Block 7: 1 Hour - Content/Proof Assets

Tasks:

- write one practical post
- draft case study from real notes
- improve one outreach message
- create one checklist or talking point

Output:

- asset that helps future sales

### Block 8: 90 Minutes - Admin And Review

Tasks:

- update tracker
- update CEO dashboard
- log objections
- prep tomorrow queue
- ask agent for follow-up drafts

Output:

- clean pipeline
- next day ready

## End-Of-Day Questions

Answer:

- How many contractors did I contact?
- How many real conversations happened?
- What did I learn?
- What objection repeated?
- What follow-up is due tomorrow?
- Did I move closer to a demo, pilot, customer, or referral?

## Sunday Review

Even if working 7 days, Sunday should be lighter and strategic.

Tasks:

- review weekly metrics
- clean tracker
- choose next week's targets
- improve scripts
- identify product/business blockers
- plan founder energy

## What To Avoid During Work Blocks

- checking random app polish
- chasing new feature ideas
- rewriting strategy docs instead of calling
- building complex automations before replies exist
- arguing with bad-fit leads
- discounting before value is proven
